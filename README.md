# 福彩3D 错后反弹软件

79 条固定公式（全史最长连错=2）的「错2期反弹」预测系统，云端全自动更新。

## 核心逻辑
- 每位置用固定公式预测杀 1 码，命中 = 杀码 ≠ 实际位
- **错2期信号**：某公式连续两期杀错 → 下一期反弹（全史反弹率 100%，因这 79 条全史从未连错 3 期）
- 输出：预测杀码 + 100 期真实回测（倒序，从近期开始）

## 云端自动更新
- GitHub Actions cron 三重备份：UTC 14:00 / 15:30 / 17:00（北京 22:00 / 23:30 / 01:00）
- 数据源双活：
  - **灰鸟主源**（`api.huiniao.top`，limit=1）：自带 next_code 跨年期号回绕
  - **17500 备份源**（`17500.cn/getData/3d.TXT`，官方全量）：重试3次+换UA防429，补漏 + 交叉验证
- 每日抓取最新开奖 → 追加 `data/fc3d-history.csv`（不覆盖）→ 生成 `static/index.html` → 部署 GitHub Pages

## 文件
- `rebound.py` — 主脚本（公式 + 引擎 + 抓取 + 算法 + HTML 生成）
- `data/fc3d-history.csv` — 历史数据（只读源，云端自动追加）
- `static/index.html` — 自包含预测网页（手机友好）
